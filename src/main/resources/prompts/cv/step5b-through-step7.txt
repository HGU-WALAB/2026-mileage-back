**Minimum CSS (STEP 4-B + readability):**
- **Fonts:** `<head>` must include Google Fonts `preconnect` + `<link>` for Noto Sans KR (400–700). First line inside `<style>`: `@import` the same Google Fonts URL so glyphs load even without `<link>`.
