# STEP 4: USER-SELECTED DESIGN OPTIONS

The portfolio design MUST adapt based on the user-selected options in `[design_preferences]`.
If the `[design_preferences]` block is missing or empty, **skip STEP 4 entirely** and use the default blue style in STEP 5-A.

## 4-A. Layout Style (archetypes — STEP 5 ships matching CSS + HTML skeleton)

User may choose ONE of: 단일 칼럼 / 랜딩 페이지 / 사이드바 / 카드 그리드

| 레이아웃 | Archetype | Recommended theme | Body wrapper class |
|----------|-----------|-------------------|-------------------|
| 단일 칼럼 | **Typographic Editorial** | indigo | `.layout-editorial` |
| 랜딩 페이지 | **Immersive Web** | cyan | `.layout-immersive` |
| 사이드바 | **Dark Dev Portfolio** | emerald | `.layout-darkdev` |
| 카드 그리드 | **Bento Dashboard** | amber | `.layout-bento` |

You **must** use the wrapper + class names from the embedded layout snippet. A generic vertical stack of `.section-card` only is **invalid** when the user chose 랜딩/사이드바/그리드.

### 단일 칼럼 — Typographic Editorial
- Serif + sans mix; italic bio pull-quote (`.editorial-bio`); timeline dots (`.editorial-timeline`).
- Top **gradient banner** `.editorial-hero` (not a flat doc header only).
- Max-width ~680px column `.editorial-body`; skills in **2-column** `.editorial-skills-grid`.
- Print-friendly; document-style reading flow.

### 랜딩 페이지 — Immersive Web (≠ 단일 칼럼)
- Full-bleed `.immersive-hero` gradient + decorative rings; `.immersive-nav` sticky with anchor links.
- Alternating `.immersive-band--light` / `--tint` section backgrounds.
- Projects in **3-column** `.projects-featured` grid; award activities as gradient `.immersive-activity-card.is-award`.
- Footer `.immersive-footer-cta`.

### 사이드바 — Dark Dev Portfolio
- `.layout-darkdev`: dark sidebar `#0a0f0d` + light `.main`.
- `.sidebar-avatar` (conic gradient), skill bars on dark track, `.sidebar-cert-pill`, dividers.
- Main: `.main-bio-card`, stacked `.main-project-card`, `.main-activity-list`.

### 카드 그리드 — Bento Dashboard
- `.bento-grid` asymmetric `2fr 1fr 1fr`; `.bento-award-card` gradient highlight cell.
- Dark `.bento-card--dark` for bio/contact; `.bento-project-card` per project; full-width activities row.

## 4-B. Color Theme
User may choose ONE of: indigo / emerald / slate / rose / amber / cyan

Token system:
```json
{
  "indigo":  { "primary": "#6366F1", "secondary": "#818CF8", "soft": "#C7D2FE" },
  "emerald": { "primary": "#10B981", "secondary": "#34D399", "soft": "#A7F3D0" },
  "slate":   { "primary": "#334155", "secondary": "#64748B", "soft": "#CBD5E1" },
  "rose":    { "primary": "#F43F5E", "secondary": "#FB7185", "soft": "#FFE4E6" },
  "amber":   { "primary": "#F59E0B", "secondary": "#FBBF24", "soft": "#FEF3C7" },
  "cyan":    { "primary": "#06B6D4", "secondary": "#22D3EE", "soft": "#CFFAFE" }
}
```

Color usage rules:
- primary → headings / buttons / emphasis
- secondary → hover / accents / gradients
- soft → badge background / section tint / chips **only** (small surfaces). Never use `soft` as `html` or `body` background — full-page backgrounds must stay **neutral** (e.g. `#f8fafc`, `#f9fafb`, or equivalent gray-50/slate-50). Using theme `soft` as the page wash lowers contrast and increases eye strain.
Do not introduce unrelated dominant colors.

## 4-C. Density Mode
- **1페이지 내:** Add class `density-one-page` on `<body>`. Merge STEP 5 **density CSS snippet**. Mark at most **3** featured projects without `.secondary-project`; hide extra projects/activities/mileage with `.secondary-project` / `.secondary-activity` / `.secondary-mileage` (hidden in screen + print). Compress padding; print `font-size: 10pt`. Tech stack: show top skills by % or compact pills — do not list 9 full progress bars if that breaks one A4 page.
- **페이지 제한 없음:** Full detail allowed; do not apply `.secondary-*` hiding.

## 4-D. Additional Custom Requests
Reflect extra user customization (preferred emphasis areas, section reorder requests, wording preferences) unless they conflict with honesty, readability, accessibility, or print usability.
