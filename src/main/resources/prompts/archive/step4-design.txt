# STEP 4: USER-SELECTED DESIGN OPTIONS

If the `[design_preferences]` block is missing or empty, **skip STEP 4 entirely** and use the default blue style in STEP 5-A.

## 4-A. Layout Style
User may choose ONE of: 단일 칼럼 / 랜딩 페이지 / 사이드바 / 카드 그리드

STEP 5 embeds **layout-specific CSS + skeleton** — implement it; do not default to one vertical `.section-card` stack for every choice.

- **단일 칼럼:** `.page-single` + `.doc-header` — no hero gradient / sticky nav / project grid.
- **랜딩 페이지:** `.hero` (gradient) + `.site-nav` anchors + `.section-band` alternating backgrounds + `.projects-featured` grid when repos exist.
- **사이드바:** `.layout-sidebar` with sticky `.sidebar` + `.main`.
- **카드 그리드:** `.cards-grid` multi-column modules.

## 4-B. Color Theme
User may choose ONE of: indigo / emerald / slate / rose / amber / cyan

Token system:
```json
{
  "indigo":  { "primary": "#6366F1", "secondary": "#818CF8", "soft": "#C7D2FE" },
  "emerald": { "primary": "#10B981", "secondary": "#34D399", "soft": "#A7F3D0" },
  "slate":   { "primary": "#334155", "secondary": "#64748B", "soft": "#CBD5E1" },
  "rose":    { "primary": "#F43F5E", "secondary": "#FB7185", "soft": "#FFE4E6" },
  "amber":   { "primary": "#F59E0B", "secondary": "#FBBF24", "soft": "#FEF3C7" },
  "cyan":    { "primary": "#06B6D4", "secondary": "#22D3EE", "soft": "#CFFAFE" }
}
```

Color usage rules:
- primary → headings / emphasis
- secondary → hover / accents / gradients
- soft → badge background / section tint / chips **only** (small surfaces). Never use `soft` as `html` or `body` background — full-page backgrounds must stay **neutral** (e.g. `#f8fafc`, `#f9fafb`, or equivalent gray-50/slate-50). Using theme `soft` as the page wash lowers contrast and increases eye strain.
Do not introduce unrelated dominant colors.

## 4-C. Density Mode
- **1페이지 내:** `body.density-one-page` + density CSS snippet; hide `.secondary-*` extras; print 10pt; compress cards.
- **페이지 제한 없음:** Full reflection length allowed.

## 4-D. Additional Custom Requests
Reflect extra user customization unless they conflict with honesty, readability, accessibility, or print usability.
