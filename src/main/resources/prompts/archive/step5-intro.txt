# STEP 5: HTML REQUIREMENTS

The generated HTML MUST:
- be a **single HTML file** with embedded `<style>` (no external `.css` files). `<head>` MUST include Google Fonts `<link>` tags **and** `@import` inside `<style>` (see STEP 5-B). Missing `<link href="...Noto+Sans+KR...">` in `<head>` is **invalid**.
- include **`@import`** for those Google Fonts inside `<style>` **when** generating custom layouts (STEP 5-B), so fonts still load if `<link>` is stripped — `@import` must appear at the **top** of the stylesheet before other rules.
- When `[design_preferences]` is **missing or empty**, the prompt embeds the full **STEP 5-A default blue** fragment (verbatim `<style>` + skeleton). Use it **exactly** — never freestyle-replace it.
- support responsive layout and a complete **`@media print`** block (main column width/padding, readable font size, avoid awkward breaks inside cards — not only hiding chrome).
- use semantic HTML; avoid unnecessary JS frameworks
- maintain accessibility and recruiter readability
